# Registration Form Project

این یک پروژه‌ی فرم ثبت‌نام است که با استفاده از HTML و CSS ساخته شده است.

## ویژگی‌ها (Features)
- شامل فیلدهای نام، نام خانوادگی، ایمیل و رمز عبور.
- دارای بخش انتخاب نوع حساب (کاربری یا تجاری).
- فیلد بارگذاری تصویر پروفایل.
- فیلد متنی (Textarea) برای توضیحات کاربر.
- پذیرش قوانین و مقررات.

## تکنولوژی‌های استفاده شده
- HTML5
- CSS3

## وضعیت پروژه
این پروژه با موفقیت تکمیل شد
